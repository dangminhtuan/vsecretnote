📖 Hướng Dẫn Sử Dụng Trong Word / Notepad / Photoshop:
  1. Tải file font V2B-ViScript.ttf bằng nút trên hoặc đã được cài đặt sẵn vào Windows.
  2. (Nếu chưa cài): Click đúp vào file V2B-ViScript.ttf → Chọn "Install" (Cài đặt).
  3. Gõ đoạn văn tiếng Việt vào ô trên → Click "Sao Chép Văn Bản" hoặc "Copy PUA".
  4. Mở Word/Notepad/Illustrator → Dán (Ctrl+V) → Bôi đen toàn bộ → Chọn font chữ "V2B ViScript".
  5. Kết quả: Đoạn văn sẽ biến thành hệ chữ tượng hình hình học ngoài hành tinh! Bạn có thể tăng giảm cỡ chữ (12pt, 24pt, 48pt...) hay bôi màu tùy ý như chữ tiếng Anh/Hàn thông thường.
